# UML Studio

Редактор UML-диаграмм: слева текст, справа готовый PNG. Работает по тому же
принципу, что PlantUML — диаграмма описывается текстом, — но дополнительно
позволяет объявлять **собственные виды объектов, связей и целые структуры**.

Разбор текста, раскладка и отрисовка выполняются внутри программы. Java,
Graphviz и сетевые сервисы не нужны — только Python и Pillow.

## Запуск

```powershell
pip install -r requirements.txt
python main.py                          # окно редактора
python main.py examples\classes.uml     # окно с открытым файлом
python main.py examples\classes.uml -o classes.png   # только собрать PNG
python main.py examples\classes.uml -o big.png -s 2  # PNG в двойном размере
```

PNG files don't add to git.

## Что умеет окно

| | |
|---|---|
| Редактор | нумерация строк, подсветка синтаксиса, отмена, авто-отступ, Ctrl+колесо — размер шрифта |
| Предпросмотр | обновляется на ходу, колесо прокручивает, Ctrl+колесо масштабирует, перетаскивание панорамирует, двойной щелчок — по размеру окна |
| Проблемы | ошибки и предупреждения разбора списком и точками на полях; двойной щелчок переходит к строке |
| Конструкторы | «Свой объект», «Своя связь», «Своя структура» — диалоги с живым предпросмотром, вставляют готовый текст |
| Экспорт | PNG в 1x–4x, прозрачный фон по желанию; F9 сохраняет рядом с исходником |
| Оформление | четыре темы диаграммы (light, dark, mono, blueprint) и светлое/тёмное оформление окна |
| Подсказки | у каждой кнопки, галочки и поля есть надпись, а при наведении — пояснение с горячей клавишей |

Кнопки масштаба (`−`, `по размеру`, `100%`, `+`) стоят в строке состояния рядом
с текущим значением масштаба.

Оформление окна (`Вид → Оформление редактора`) переключает не только рабочую
область, но и системные части: заголовок с кнопками сворачивания и закрытия,
строку меню и выпадающие меню, раскрывающиеся списки, полосы прокрутки, рамки
полей и обводку выделения. Тёмный заголовок окна рисует сама Windows, поэтому
он появляется начиная с Windows 10 версии 2004; на более старых сборках и на
других системах заголовок остаётся системным. Окна выбора файла, цвета и
сообщения тоже рисует система — они следуют её собственной настройке.

Горячие клавиши: `F5` — обновить, `F1` — справка по синтаксису, `F9` — быстрый
экспорт, `F2` — переименовать имя под курсором, `Ctrl+Z` — отменить,
`Ctrl+Shift+Z` — вернуть, `Ctrl+F` — найти, `Ctrl+H` —
заменить, `Ctrl+/` — закомментировать строки, `Ctrl+E` — экспорт PNG, `Ctrl+1/2/3` — конструкторы объекта, связи и
структуры, `Ctrl+0` — по размеру окна. Сочетания с Ctrl действуют и на русской
раскладке: срабатывает та же физическая клавиша, что и в латинице.

## Синтаксис в двух словах

Полная справка встроена в программу (`F1`). Ниже — главное.

### Объекты и связи

```
class Счёт {
  + номер: string
  - баланс: decimal
  --
  + пополнить(сумма): bool
  {abstract} + закрыть()
}

interface Хранилище
abstract class База
enum Статус { НОВЫЙ, ЗАКРЫТ }
database PG
actor Клиент

База <|-- Счёт                 наследование
Счёт ..|> Хранилище            реализация
Счёт "1" *-- "0..*" Операция   композиция с кратностями
Счёт --> Статус : состояние    ассоциация с подписью
Счёт ..> PG                    зависимость (пунктир)
```

Видимость: `+` открытое, `-` закрытое, `#` защищённое, `~` пакетное.
Параметры связи задаются в скобках: `A -[#c62828,dashed,up]-> B`,
`A -[hidden]-> B` влияет только на раскладку.

### Свой вид объекта

```
shape Микросервис {
  form: roundrect
  accent: #1565c0
  stereotype: service
  sections: Ручки, SLA
}

shape Критичный extends Микросервис {
  accent: #c62828
  stroke-width: 2.4
}

Микросервис Каталог {
  Ручки:
    + GET /items
  SLA:
    99.9%
}
```

Доступные формы: `rect`, `roundrect`, `stadium`, `ellipse`, `circle`, `ring`,
`dot`, `cylinder`, `hexagon`, `diamond`, `cloud`, `note`, `folder`,
`component`, `node3d`, `queue`, `document`, `actor`.

### Свой вид связи

```
link поток {
  line: solid
  head: arrow_filled
  color: #ef6c00
  width: 2
}

Каталог -[поток]-> Очередь
```

### Своя структура

Структура — это шаблон из объектов и связей, который разворачивается одной
строкой. Параметры подставляются как `$Имя` или `${Имя}`.

```
struct Трёхслойный(Имя, БД) {
  class ${Имя}Api
  class ${Имя}Логика
  database $БД
  ${Имя}Api --> ${Имя}Логика
  ${Имя}Логика --> $БД
}

package "Заказы" { use Трёхслойный(Order, orders_db) }
package "Склад"  { use Трёхслойный(Stock, stock_db) }
```

### Оформление документа

```
title Заголовок
caption подпись под картинкой
legend
пояснение к обозначениям
endlegend

set theme = light        light | dark | mono | blueprint
set direction = LR       TB | LR | BT | RL
set node_sep = 44        зазор между объектами
set rank_sep = 68        зазор между уровнями
set transparent = on     прозрачный фон PNG
set scale = 1.5          множитель размера
```

## Устройство кода

```
main.py                точка входа: окно или командная строка
umlstudio/
  parser.py            текст -> модель (единственное место, знающее синтаксис)
  model.py             Diagram, Node, Edge, Group, ShapeDef, LinkDef, StructDef
  theme.py             палитры, встроенные виды объектов и связей
  style.py             шрифты, разрешение стилей, обмер объектов
  layout.py            послойная раскладка и трассировка связей
  geometry.py          границы форм, пунктир, скругление углов
  shapes.py            рисование форм
  arrows.py            рисование окончаний связей
  renderer.py          модель с координатами -> изображение Pillow
  api.py               build() и render_to_file()
  gui/
    app.py             главное окно, фоновый поток отрисовки
    editor.py          редактор с подсветкой
    preview.py         полотно предпросмотра
    dialogs.py         конструкторы и справка
    examples.py        встроенные примеры и текст справки
    palette.py         цвета оформления окна
    native.py          заголовок окна средствами Windows
    tooltip.py         всплывающие подсказки
examples/              те же примеры отдельными файлами
```

Обмер текста и раскладка используют один и тот же `StyleResolver`, поэтому
картинка всегда соответствует расчёту. Раскладка построена по схеме Сугиямы:
снятие циклов, распределение по уровням, уменьшение числа пересечений
(медианная эвристика), расстановка координат изотонической регрессией,
ортогональная трассировка связей. Вложенные пакеты раскладываются рекурсивно:
каждая группа сначала считается отдельной диаграммой, а затем участвует в
раскладке родителя как один прямоугольник.

Сглаживание получается за счёт отрисовки с двукратным увеличением и
последующего уменьшения, поэтому отдельного антиалиасинга в коде нет.

## Использование как библиотеки

```python
from umlstudio import build, render_to_file

result = build("class A\nA --> B")
result.image.save("out.png")          # PIL.Image
print(result.size, result.duration)
for problem in result.diagnostics:
    print(problem)

render_to_file(open("d.uml", encoding="utf-8").read(), "d.png", scale=2)
```
